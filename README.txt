2026 부산 문화다양성 주간 아카이빙 웹진

GitHub Desktop 업로드 방법
1. 이 ZIP 파일을 먼저 압축 해제합니다.
2. webzine-final-light 폴더 안의 index.html, pages, videos, images, fonts를 모두 선택합니다.
3. GitHub Desktop에서 Repository > Show in Explorer로 저장소 폴더를 엽니다.
4. 선택한 파일과 폴더를 붙여넣고 기존 파일을 교체합니다.
5. Commit to main을 누른 뒤 Push origin을 누릅니다.
6. index.html이 저장소 최상단에 있어야 합니다.

구동 방식
- 화면 오른쪽: 다음 페이지 / 화면 왼쪽: 이전 페이지
- 키보드 방향키와 모바일 좌우 스와이프 지원
- 오른쪽 위 메뉴 버튼: 목차 열기
- 6페이지 왼쪽 썸네일: 2026 부산문화다양성 주간 티저영상 재생
- 6페이지 오른쪽 썸네일: 문화다양성 주간행사 통합 스케치영상 재생
- 영상 썸네일 클릭 시 확대 재생
- 확대 영상 바깥 오른쪽 클릭: 다음 페이지
- 확대 영상 바깥 왼쪽 클릭: 이전 페이지
- ESC: 영상 또는 목차 닫기
